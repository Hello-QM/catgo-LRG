# Cu 表面 C-N 偶联反应中阳离子效应的理论研究

## 一、研究背景与科学问题

电催化 CO₂ 还原（CO₂RR）和 NO₃⁻ 还原（NO₃RR）是将温室气体和水体污染物转化为高附加值含氮有机产物（如尿素、甲酰胺、氨基酸前体）的重要途径。在 Cu 基催化剂上，CO₂RR 产生的 C 中间体（CO、CHO、CH₂O 等）与 NO₃RR 产生的 N 中间体（NO、NH₂ 等）有可能在表面发生 **C-N 偶联**，直接生成 C-N 键产物。

然而，C-N 偶联反应面临以下关键挑战：
- **偶联路径众多**：5 种 C 中间体 × 8 种 N 中间体 = 40 种可能的偶联组合，哪些路径热力学和动力学可行？
- **反应能垒高**：C-N 成键需要克服显著的活化能垒，如何降低？
- **阳离子效应不明确**：电解液中的碱金属阳离子（Li⁺、K⁺）如何影响 C-N 偶联能垒？是通过静电稳定过渡态，还是通过改变溶剂化结构？

本研究旨在系统地回答上述问题。

## 二、研究体系

### 2.1 催化剂表面

- **Cu(100)**：4×4 超胞，3 层 Cu（48 个 Cu 原子），底层固定
- 晶胞参数：10.224 × 10.224 × 37.611 Å
- 选择 Cu(100) 的原因：实验上 Cu(100) 对 C₂ 产物和含氮产物具有较高选择性

### 2.2 电化学界面模型

- **显式水层**：49 个水分子（~3-4 层水），提供真实的溶剂化环境
- **阳离子**：Li⁺ 或 K⁺（各 1 个），模拟电解液中的阳离子效应
- **总原子数**：~200 个/体系

### 2.3 反应中间体

**C 物种**（来自 CO₂RR）：

| 中间体 | 化学式 | C 氧化态 | 特征 |
|--------|--------|----------|------|
| CO₂ | CO₂ | +4 | 线性，弱活化 |
| *COOH | COOH | +3 | 羧基自由基 |
| *CO | CO | +2 | 表面吸附 CO，最活泼的 C 物种 |
| *CHO | CHO | +2 | 甲酰基 |
| *CH₂O | CH₂O | 0 | 甲醛，C 趋于饱和 |

**N 物种**（来自 NO₃RR，从 NO₂ 开始计算）：

| 中间体 | 化学式 | N 氧化态 | 特征 |
|--------|--------|----------|------|
| *NO₂ | NO₂ | +4 | N 被 O 包围，偶联受限 |
| *NO | NO | +2 | 表面吸附 NO，N 暴露 |
| *NOH | NOH | +1 | N-羟基 |
| *NHOH | NHOH | -1 | 羟胺，亲核性 N |
| *HNO | HNO | +1 | 亚硝酰 |
| *N | N | -3 | 吸附 N 原子，高活性 |
| *NH | NH | -3 | 亚胺，强亲核体 |
| *NH₂ | NH₂ | -3 | 胺，强亲核体 |

### 2.4 C-N 偶联路径

经化学可行性筛选，**39 条偶联路径可行**（40 条中仅 CO₂ + NO₂ 因两者均为高氧化态且无自由基特征被排除）。

**偶联类型分类：**

| 偶联类型 | 机理 | 典型路径 | 预期产物 |
|---------|------|---------|---------|
| 亲核偶联 | 亲核性 N 进攻亲电性 C | CO + NH₂ → CONH₂ | 尿素前体 |
| 自由基偶联 | 两个自由基物种结合 | CO + NO → CONO | 亚硝酰羰基 |
| 混合偶联 | 无明确亲核/亲电区分 | CO₂ + NO → CO₂NO | 混合产物 |

**重点研究路径**（基于文献和化学直觉）：
1. **CO + NH₂ → CONH₂**（尿素合成关键步骤）
2. **CO + N → CON**（异氰酸酯类）
3. **CHO + NH₂ → CHONH₂**（甲酰胺）
4. **CO + NO → CONO**（自由基偶联）
5. **COOH + NH₂ → COOHNH₂**（甘氨酸前体）

### 2.5 阳离子效应条件矩阵

每条偶联路径需要在 **5 种条件**下分别计算：

| 条件标签 | 描述 | 目的 |
|---------|------|------|
| no_cation | Cu + 水层，无阳离子 | 基线参考 |
| Li_near | Li⁺ 在 Cu-水界面附近，与吸附物成键 | Li⁺ 近场效应 |
| Li_far | Li⁺ 在水层深处，远离吸附物 | Li⁺ 远场/间接效应 |
| K_near | K⁺ 在 Cu-水界面附近，与吸附物成键 | K⁺ 近场效应 |
| K_far | K⁺ 在水层深处，远离吸附物 | K⁺ 远场/间接效应 |

**阳离子效应量化**：ΔΔG‡ = G‡(with cation) - G‡(no cation)

## 三、计算方法

### 3.1 计算软件与参数

- **DFT 软件**：VASP 6.x（需编译 VTST + TPOT/CP-VASP 补丁）
- **泛函**：PBE + D3(BJ) 色散校正
- **截断能**：ENCUT = 400-520 eV
- **K 点**：Gamma-only（大超胞）
- **电子步收敛**：EDIFF = 1E-5 eV
- **Smearing**：Gaussian，SIGMA = 0.1 eV

### 3.2 计算流程

每条偶联路径的完整计算流程如下：

```
Step 1: 建模
  Cu(100) slab + 双吸附物（C 物种 + N 物种）+ 水层 + 阳离子
  ↓
Step 2: 结构优化
  VASP 几何优化（ISIF=2），固定底层 Cu
  ↓
Step 3: AIMD 平衡化
  NVT 系综，300 K，Nosé-Hoover 恒温器（SMASS=0）
  5000-10000 步 × 1 fs = 5-10 ps
  目的：平衡水层结构和阳离子位置
  ↓
Step 4: Slow-Growth AIMD（核心步骤）
  约束变量：C-N 原子间距离
  ICONST 文件定义 C-N 距离约束
  INCREM = -0.005 Å/step（从 ~4.0 Å 缩短到 ~1.4 Å）
  总步数：~520 步（NSW = 10000，含平衡步）
  LBLUEOUT = .TRUE.（输出自由能梯度到 REPORT 文件）
  ↓
Step 5: 恒电位校正
  使用 TPOT 或 CP-VASP 方法
  两步法：
    (a) 静态 SCF 确定 NELECT（Step 1 INCAR）
    (b) 生产运行时固定 NELECT（与 Step 4 结合）
  ↓
Step 6: 数据分析
  解析 REPORT 文件 → 提取自由能变 ΔF(ξ)
  Blue Moon 集成平均：ΔF = ∫ <|Z|^(-1/2) · (λ + GkT)>_ξ dξ
  前向能垒 = max(ΔF) - ΔF(initial)
  逆向能垒 = max(ΔF) - ΔF(final)
```

### 3.3 Slow-Growth Method 详解

Slow-growth method（慢增长法）是基于热力学积分的自由能计算方法：

- **原理**：沿反应坐标 ξ（这里是 C-N 距离）缓慢变化，在每一步记录约束力
- **ICONST 文件格式**：
  ```
  R C_idx N_idx 0
  ```
  R 表示距离约束，C_idx 和 N_idx 是 C 和 N 原子的索引（1-based），0 表示从 INCREM 读取变化速率

- **INCREM 文件**：
  ```
  -0.005
  ```
  每个 MD 步骤中 C-N 距离减少 0.005 Å

- **输出**：REPORT 文件包含每步的 Lagrange 乘子 λ、度量因子 |Z|^(-1/2) 和几何校正 GkT

### 3.4 恒电位方法

由于电化学反应发生在恒定电极电位下，而 AIMD 模拟在恒电荷条件下进行，需要恒电位校正：

**TPOT 方法**：
- LTPOT = .TRUE.
- TPOTVTARGET：目标电位（V，真空标度）
- 两步法确定 NELECT 后进行恒电位 MD

**CP-VASP 方法**：
- LCEP = .TRUE.
- TARGETMU：目标化学势（eV，如 -4.44 eV 对应 0 V vs SHE）
- 配合 VASPsol++ 隐式溶剂

## 四、预期结果与分析

### 4.1 反应能垒对比

| 分析维度 | 预期产出 |
|---------|---------|
| 路径筛选 | 识别能垒最低的 C-N 偶联路径（最优偶联组合） |
| 阳离子效应 | ΔΔG‡ 值：阳离子使能垒降低/升高多少 |
| 离子种类效应 | Li⁺ vs K⁺ 对能垒的不同影响（离子半径效应） |
| 距离效应 | 近表面 vs 远离表面的阳离子效应差异（直接 vs 间接效应） |

### 4.2 分析方法

1. **自由能曲线 ΔF(ξ)**：从 REPORT 文件提取，绘制沿 C-N 距离的自由能变化
2. **能垒对比表**：5 种条件 × N 条路径的系统对比
3. **电荷分析**：Bader 电荷分析过渡态处的电荷转移
4. **结构分析**：过渡态构型中阳离子与吸附物的几何关系
5. **溶剂化结构**：水分子在偶联过程中的重组

### 4.3 预期科学发现

- 碱金属阳离子通过**静电稳定**降低 C-N 偶联过渡态能垒
- K⁺ 的效果可能强于 Li⁺（更大离子半径 → 更分散的正电荷 → 更稳定的界面电场）
- 阳离子**近表面**时效果显著，**远离表面**时效果减弱 → 证明是直接的近场效应
- 可能发现 1-2 条最优偶联路径作为合成含氮产物的设计指导

| **总计** | | | **~8000-39000 h** |

（基于 48 核/节点估算，实际取决于 HPC 配置）

**建议策略**：
1. 先计算 3-5 条重点路径（CO+NH₂, CO+N, CHO+NH₂ 等）
2. 根据结果决定是否扩展到全部路径
3. 每条路径先做 no_cation 基线，再加阳离子条件
