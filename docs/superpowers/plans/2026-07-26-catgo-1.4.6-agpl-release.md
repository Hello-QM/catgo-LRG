# CatGo 1.4.6 AGPL Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release CatGo 1.4.6 under AGPL-3.0-or-later with unverified PORMAKE data excluded, explicit-source MOFX-DB access retained, and all normal downloads and automatic updates served through Cloudflare.

**Architecture:** Restore one canonical AGPL legal bundle and synchronize it into every package and application artifact. Extend the fail-closed release-rights verifier with evidence-backed `NOTICE_BACKED` and mechanically verified `EXCLUDED` states, remove the bundled PORMAKE/reticular feature, preserve MOFX-DB as a six-source search-only feature, and retain the existing exact-source, signed-artifact, transactional R2, and finalizer publication pipeline.

**Tech Stack:** Node.js test runner and file-system tooling, Svelte 5 and TypeScript, Python 3.10+/FastAPI/Pydantic/pytest, Rust/Cargo, pnpm/Vitest/Playwright, GitHub Actions, Tauri, Cloudflare Workers and R2.

## Global Constraints

- CatGo 1.4.6 first-party release surfaces use exactly `AGPL-3.0-or-later`.
- Acknowledgement and citation remain prominent requests, never additional AGPL conditions.
- No active surface may claim that commercial use requires separate permission.
- Remove `server/catgo/vendor/pormake/` completely, including all 3,274 database files.
- Remove every bundled reticular builder API, CLI, MCP, schema, frontend, and active skill entrypoint.
- Retain MOFX-DB only for explicit `CoREMOF 2014`, `CoREMOF 2019`, `CSD`, `hMOF`, `IZA`, or `PCOD-syn` requests.
- Blank, omitted, unknown, unfiltered, and `Tobacco` MOFX-DB requests fail before any network call.
- Release-rights verification accepts only evidence-backed `CLEARED`, `NOTICE_BACKED`, and `EXCLUDED`; it rejects `BLOCKED`, `UNKNOWN`, `REVIEW_REQUIRED`, missing, and unsupported states.
- Do not rewrite missing adopted-revision history as known provenance.
- Keep exact-tag/source verification, signatures, all-platform asset policy, R2 receipts and rollback, `latest.json`-last publication, and finalizer-only public release.
- Downloads, VS Code sidecars, and in-app updates use only `https://dl.catgo-ucsd.org` as their normal origin.
- Version remains exactly `1.4.6` / tag `v1.4.6`.
- Follow TDD: change or add a test, observe the intended failure, make the minimum production change, and rerun to green.
- Commit after every implementation task.
- Every shell command starts with `rtk`.
- Do not stage or modify `.claude/gate-approvals/`, `.claude/tmp-dump.traj`, or `.superpowers/`.
- The trajectory release gate uses `/home/james0001/Downloads/dump.traj`, SHA-256 `38d4554e93744b7efc53e2add4f7ef90ed8f72557b78e45f0696347434b3e41c`, 100 frames, and 19,968 atoms.
- The real trajectory must retain 100/100 exact bond graphs and at least 24 unique presented frames/s in both measured segments.
